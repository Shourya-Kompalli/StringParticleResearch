# StringParticleResearch

## Computational Investigation of Novel Particle-Like Excitations in String-Theoretic Models

This repository contains the mathematical derivations, numerical simulations,
data, validation tests, and research documentation for an investigation into
whether a mathematically consistent string-theoretic model can produce a
previously unidentified particle-like excitation.

## Research Principle

We do not assume that a new particle exists.

The investigation will determine whether the mathematics and numerical
simulations produce a stable, spectrally distinguishable excitation that
cannot be explained as a known string excitation, harmonic, resonance,
Kaluza-Klein mode, winding mode, or numerical artifact.
